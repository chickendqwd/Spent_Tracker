# Spent Tracker · UI 设计说明（README）

> 本文档记录 Spent Tracker 界面设计的已确认口径、配色与图标选择理由、组件规范及未决项。
> 基线版本：代码 v3.1（Flutter + Riverpod + Hive + fl_chart，本地离线存储）。
> 状态：**Bright 方向已收敛，Dark 版与其余页面尚未展开**；本文档为设计口径稿，不是最终代码实现。

---

## 1. 产品定位

- **是什么**：个人记账应用，记录支出与收入，支持时间分析、预算、多币种、导入导出、年度报告。
- **使用场景**：日常高频、长时间反复打开的工具型应用；用户每天可能记账、复盘收支、查看预算。
- **设计关键词**：**钱（储蓄与收支）、规划（预算与目标）、自律（坚持记账、克制消费）**。
- **整体调性**：不单调、也不浮夸；低饱和、耐看、信息优先，风格化让位于可读性。

### 设计取舍背景
- 探索过程中排除了纯默认 Material 风（太单调）和强海报撞色风（易疲劳、不适合长期使用）。
- 参考过《Persona 5》式高对比排版与转场语言，只借鉴其**层级节奏、斜切几何、动效编排思路**，不照搬红黑怪盗视觉（见第 8 节）。
- 最终采用「青碧票据拼贴」方向，收敛为干净的低饱和青绿工具风。

---

## 2. 已确认的设计方向

- **主风格**：低饱和灰青绿（鼠尾草绿）工具风，带轻微票据/手账语言。
- **背景**：白 → 浅灰纵向渐变，无纹样、无装饰图案，视觉位置留给内容与数字。
- **应用内分类图标**：系统原生彩色 Emoji，浅灰圆形底；后续允许用户自行添加自定义 Emoji。
- **卡片语言**：统一斜切角卡（右上角斜切 + 左侧 4px 主色竖条）。
- **模式策略**：一套布局同时出 Bright / Dark 两套皮肤，结构、层级、组件位置保持一致，只换明暗与配色；**本轮先定 Bright，Dark 待 Bright 最终确认后再做**。

## 3. 色彩规范（Bright）

### 3.1 色板

| 角色 | 色值 | 用途 |
|---|---|---|
| 页面背景渐变 上 | `#FFFFFF` | 页面顶部底色 |
| 页面背景渐变 下 | `#EEF0F2` | 页面底部底色 |
| 卡片底色 | `#FBFAF7` | 所有内容卡片、列表容器 |
| 主色 Primary | `#5E8B7E` | 选中态、主卡色条、进度条、主按钮、导航选中 |
| 深青碧 Deep Teal | `#1F5F56` | 主色加深版本，用于强调、图表深色段、图标底色 |
| 辅助陶土 Clay | `#B98A6F` | 次要点缀、图标辅助色、装饰色块 |
| 收入 Income | `#6B8E5A`（橄榄绿） | 收入金额、收入图例、正向数据 |
| 支出 Expense | `#B0563F`（陶土红棕） | 支出金额、支出图例、负向数据 |
| 主文字 Ink | `#202020` | 标题、金额、主要正文 |
| 次要文字 Muted | `#7A8288` | 标签、备注、轴标签、说明文字 |
| 分隔线 | `#D8DEE0` | 列表分隔线、卡片描边 |

### 3.2 图表循环配色（低饱和，按分类循环取用）
`#5E8B7E`（灰青绿）、`#7FA6B8`（灰蓝）、`#C9B87A`（芥黄）、`#B98A6F`（陶土）、`#6B8E5A`（橄榄绿）、`#9AA3A8`（中性灰）。

### 3.3 为什么选这套颜色

**主色用灰青绿，而不是常见的金融蓝或纯绿：**
- 绿色天然关联「金钱、储蓄、成长」，比冷蓝更有温度；
- 选用**低饱和鼠尾草绿**而不是鲜艳翠绿，避免理财类 App 的攻击性和廉价感，契合「克制、自律、长期使用」的气质；
- 灰青绿在亮底和暗底下都容易压低/提亮，方便后续做 Dark 模式保持一致。

**辅助色用柔陶土：**
- 青绿偏冷，陶土暖棕做小面积平衡，让界面有人情味而不至于冷硬；
- 陶土只用于点缀和次要元素，不铺开，避免和主色争抢重心。

**支出不用纯红，改用陶土红棕：**
- 纯红警示感太强，日常记账反复看到容易焦虑、视觉疲劳；
- 红棕在保留「支出/负向」语义的同时更柔和，和整体低饱和体系统一。

**收入用橄榄绿，和主色拉开色相：**
- 避免主色绿与收入绿混在一起导致语义不清；收入绿偏黄调，主色偏青调，列表里一眼可分。

**背景用白灰渐变而非纯色或纹理：**
- 记账是高频工具，纯白略显生硬，纯灰又显脏；白到浅灰的轻微纵向渐变提供层次，但不抢内容；
- 不使用背景纹样、插画底纹，保证长列表阅读不被干扰。

**整体低饱和、高对比只留给数字：**
- 颜色克制是为了长期耐看；真正需要显眼的是结余金额和收支数字，靠字号、字重和语义色突出，而不是靠大面积艳色。

### 3.4 Dark 模式预留（未定稿）
- 保持同一套布局与组件，背景压深为深靛灰/炭灰，卡片转深蓝灰；
- 主色提亮为浅青绿以保证暗底对比度；支出/收入语义色相应提亮；
- 具体色值等 Bright 确认后单独出 Dark 色板，并做明暗对照检查。

## 4. 应用图标设计

### 4.1 选定方案：收支加减号

选定图标（参考图）：
![应用图标 · 收支加减号](https://aka.doubaocdn.com/s/jL5nDmOT1Y)

- **构成**：浅色圆角方形底，内部白色卡片被细竖线分为左右两半；左半橄榄绿加号 `+`（收入），右半陶土红棕减号 `−`（支出）。
- **当前为 3D 浮雕预览效果；定稿时压成扁平柔和块面**，去掉高光和厚投影，与界面风格一致。

### 4.2 为什么选这个图标

1. **语义最直接**：`+` / `−` 就是这个应用的两个核心动作——记一笔收入、记一笔支出，用户不需要解释就能看懂「这是记账/算账工具」。
2. **对称稳定**：左右等分、加减对置，天然表达「收支平衡」，和预算、结余的产品概念一致。
3. **小尺寸可辨**：加号、减号是最简几何形，缩到桌面 16–48px 仍然清晰，不依赖细节。
4. **可单色化**：图形结构不依赖色彩和渐变，方便做单色版、反白版和 Android 自适应图标分层。
5. **不绑定形象**：没有动物、吉祥物或文化隐喻，后续品牌延展和跨语言使用没有识别障碍，也不存在 IP 授权问题。

### 4.3 被排除的备选及原因

| 备选方向 | 排除原因 |
|---|---|
| 账本清单 + 对勾 | 贴记账本职、也呼应界面卡片，但图形元素更多，小尺寸下清单线条和对勾会挤；品牌一致性虽好，识别速度略逊于加减号 |
| 硬币 + 上升折线 | 增长/理财感强，但折线箭头更像股票、投资类应用，日常收支记录的语义偏弱 |
| 钱包 + 硬币 | 存钱直观亲和，但钱包搭扣细节复杂，小尺寸轮廓不够干净 |

### 4.4 图标后续待产出
- 主图标（彩色扁平版，1024×1024 上架尺寸）；
- Android 自适应图标：前景层 / 背景层分层；
- iOS 圆角方形版、单色版、反白版；
- Dark 模式对应图标；
- 单色剪影测试与最小尺寸可读性检查。

## 5. 组件与卡片规范

### 5.1 斜切角卡片（统一容器）
- 底色：`#FBFAF7`；圆角：14px；
- 右上角一道斜切角（呼应票据语言）；
- 左侧 4px 宽主色 `#5E8B7E` 竖色条；
- 极柔浅灰投影，不使用重阴影；
- 卡片间距统一 16px，卡片内边距 16px。

### 5.2 导航与入口
- **底部导航**：总览 / 明细 / 设置 三项；选中态用主色，未选中用次要文字色。
- **悬浮录入按钮（FAB）**：主色圆形按钮，居中凸起，仅在非设置页展示；核心动作「记一笔」保持全局可达。

### 5.3 筛选与控件
- **时间范围筛选**：圆角胶囊，选中态主色填充白字，未选中浅底；选项为本周 / 本月 / 近 7 天（趋势图区间后续独立扩展）。
- **进度条（预算）**：圆角细条，已用部分主色；超支时切换为支出红棕。
- **图表**：双线折线图（支出/收入）、环形占比图 + 金额排行；配色走 3.2 图表色板，配图例和具体金额，不只给图形。
- **列表条目**：左侧浅灰圆形 Emoji 头像，中间分类名 + 备注小字，右侧语义色金额。

### 5.4 为什么用斜切角卡而不是纯圆角卡或票根缺口卡
- 纯圆角白卡最通用但缺少记忆点；票根缺口手账感最强但装饰偏重；
- 斜切角 + 左侧色条是两者的折中：保留了切面辨识度，又足够克制，能同时承载分析卡、预算卡、列表等多种模块，不会显得花哨。

## 6. 信息层级与排版

### 6.1 优先级（从高到低）
1. **结余金额**：全页最大、最粗，第一视觉焦点；
2. 总支出 / 总收入：语义色区分，字号次于结余；
3. 本月预算：紧接总账下方，让「花了多少 / 还能花多少」一目了然；
4. 趋势、分类分析等图表模块；
5. 最近记录 / 明细列表。

### 6.2 排版原则
- 字体：现代无衬线中文字体；**数字加粗**，标签和说明用次要灰色、较小字号；
- 同一模块内对齐轴统一：标题左对齐，金额右对齐；
- 金额始终带币种符号；列表/详情保留账目原币种，汇总按基准币种换算（沿用现有业务口径）；
- 不使用斜体、不堆叠多种字重；层级靠字号 + 粗细 + 颜色建立。

### 6.3 总览页结构（自上而下）
1. 顶部栏：标题「总览」+ 年报入口图标；
2. 时间范围筛选胶囊；
3. 结余主卡（结余大数字 + 支出/收入两格）；
4. 本月预算卡（进度条 + 已用/预算）；
5. 收支趋势卡（双线折线）；
6. 分类分析卡（环形图 + 排行）；
7. 最近记录列表；
8. 底部导航 + 录入 FAB。

## 7. 动效原则（借鉴 Persona 5，但调弱）

P5 的菜单从角落斜切飞入、面板砸入、条纹转场很惊艳，但其官方也承认早期「过度动画」影响可读性，最终调弱了 UI 元素。本应用沿用这条教训：

- **页面切换**：面板从右侧斜切轻滑入，带轻微错位，不做夸张砸屏；
- **录入入账**：数字滚动 + 卡片从底部轻弹入；
- **Tab 切换**：内容区淡入 + 轻微上移；
- **严肃页面**（设置、明细筛选、表单）：保持朴素直切，不加装饰动效；
- **底线**：动效只服务于位置反馈和操作确认，绝不遮挡信息、不拖慢高频操作。

## 9. 未决项与下一步

### 待确认
- Bright 主界面稿是否还有微调（斜切角度、色条粗细、主卡深浅、金额字号）；
- 图表色板在真实数据分类较多时的区分度。

### 待产出
- Dark 模式整套界面与色板（与 Bright 结构一致）；
- 其余页面设计：明细列表、录入面板、详情面板、设置各页、年度报告；
- 图标正式素材：扁平主图标、自适应分层、单色/反白版、上架尺寸；
- 完整设计规范页：网格间距、字号阶梯、圆角与投影参数、组件状态（禁用/选中/超支）；
- 落地到 Flutter 主题层：替换现有 `AppPalette` 语义色与组件样式。

### 业务口径衔接（沿用现有代码，不在设计层改动）
- 金额以整数分存储，避免浮点误差；
- 基准币种可切换，汇总换算、明细保留原币种；
- 预算按月，超支红色提示但不强制拦截；
- 周期记账仅提醒预填，不自动入账。
